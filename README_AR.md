# Bor Economic Publisher — مشروع مستقل

هذا مشروع تجريبي منفصل تمامًا عن أي مشروع Bor سابق. لا تستعمل مستودع GitHub القديم أو قاعدة بياناته أو خدمة Render القديمة.

## ماذا يفعل؟
- يحتوي على 4 مقالات اقتصادية عربية في `posts.json`.
- يحدد مقال اليوم تلقائيًا حسب التاريخ المحلي في الجزائر.
- ينشر مقالًا واحدًا يوميًا الساعة 09:00 بتوقيت الجزائر عبر Meta Graph API.
- بعد المقال الرابع يعود إلى المقال الأول.
- GitHub Actions يرسل طلب النشر كل يوم عند 08:00 UTC (09:00 في الجزائر).

## متطلبات النشر
1. إنشاء **مستودع GitHub جديد** لهذا المجلد، مثل `Bor-Economic-Publisher`.
2. إنشاء خدمة Render جديدة من هذا المستودع. لا تختَر خدمة Bor القديمة.
3. ضبط متغيرات البيئة في Render:
   - `CRON_SECRET`: سر طويل وعشوائي تختاره.
   - `FACEBOOK_PAGE_ID`: معرّف صفحة فيسبوك.
   - `FACEBOOK_PAGE_ACCESS_TOKEN`: رمز وصول صفحة صالح، لا تضعه في الملفات ولا تشاركه في المحادثة.
   - `META_GRAPH_VERSION`: إصدار Graph API صالح ومدعوم في حساب Meta لديك، مثل `v24.0` إذا كان متاحًا.
   - `PUBLISH_START_DATE`: تاريخ أول نشر بصيغة `YYYY-MM-DD` حسب تاريخ الجزائر.
4. في مستودع GitHub الجديد، افتح Settings → Secrets and variables → Actions ثم أضف:
   - `PUBLISH_URL`: رابط خدمة Render، مثل `https://your-service.onrender.com` من دون `/` أخيرة.
   - `CRON_SECRET`: نفس القيمة التي وضعتها في Render.
5. من تبويب Actions في GitHub، فعّل workflows إن طُلب منك ذلك. يمكن بدء تشغيل يدوي من `Daily Facebook publish` → `Run workflow`.

## اختبارات آمنة
- افتح `/api/health` للتحقق من عمل الخدمة.
- افتح `/api/preview` لمعاينة مقال اليوم دون نشره.
- لا تختبر `/api/publish` إلا بعد التحقق من الصفحة والصلاحيات، لأنه ينشر منشورًا فعليًا على فيسبوك.

## ملاحظات مهمة
- النشر يتطلب صفحة فيسبوك وصلاحيات Meta المناسبة ورمز وصول صفحة صالحًا. إنشاء التطبيق وحده لا يمنح صلاحية النشر تلقائيًا.
- لا تستخدم كلمة مرور فيسبوك الشخصية. لا تشارك `FACEBOOK_PAGE_ACCESS_TOKEN` أو `CRON_SECRET`.
- الجدولة على GitHub Actions قد تتأخر أحيانًا؛ أوقات cron ليست ضمانًا بالدقيقة.
- خدمة Render المجانية قد تدخل في وضع السكون، فيتأخر أول طلب أثناء الاستيقاظ. يجب اختبارها قبل الاعتماد عليها.
- هذا الإصدار الأول لا يخزّن سجلًا دائمًا يمنع التكرار إذا أُعيد تشغيل workflow يدويًا في اليوم نفسه. لا تضغط Run workflow أكثر من مرة في اليوم.
- قبل التوسع إلى 70 مقالًا أو الاعتماد طوال السنة، نضيف سجل نشر دائمًا وآلية منع التكرار وإشعارات للأخطاء.
